# LGF-DSL 速查 (写候选公式时必读)

LGF-DSL 是算符-系数语言的受限子集。**自造函数名会解析失败并整条被丢弃**。

## 允许的算子

| 类别 | 写法 | 说明 |
|---|---|---|
| 二元 | `a + b`, `a - b`, `a * b`, `a / b` | 也可写 `inv(b)` 表示 `1/b` |
| 幂 | `x^2`, `x^3`, `x^4` | 只到 4 次 |
| 一元 | `exp(x)`, `log(x)`, `sqrt(x)`, `tanh(x)`, `sin(x)`, `cos(x)`, `inv(x)`, `neg(x)` | 白名单 |
| 多项式 | `P1(x, y) = ...` 定义后引用 | 见下 |

## 系数

- **全局常数** `C1, C2, C3, ...` — 5 个工况通用, **只允许这一种** (ASM 域硬规则)
- 逐工况常数 `K1, K2, ...` — 合法但 ASM 域会**拒绝** (C4 约束)
- 常数字面量必须写成 `1`、`0.5` 等; **不要**把系数写成裸的魔术数

## 合法写法示例

```
C1 * (sqrt(roloc)) * (C2 * (log(yw)) + C3 * (roloc))
C1 * (exp(inv(C2 * (yw) + C3 * (1))))
C1 * (eta2) * (inv(C2 * (1) + C3 * (eta2)))
C1 * (tanh(C2 * (roloc))) * (log(yw + C3 * (1)))
```

## 常见错误

| 错误 | 后果 | 正确写法 |
|---|---|---|
| `sat(x)` / `esat(x)` / `gauss(x)` | 解析失败, 整条丢弃 | `tanh(C1*x)` / `C1/(K1+C2*x)` |
| `exp(C1*(1/yw))` | 在 `yw→0` 溢出/NaN | `exp(C1*(inv(yw + C2)))` |
| `log(yw)` 单独出现 | `yw→0` 发散 | `log(yw + C1)` 或配饱和因子 |
| `eta2^3` | 8 个数量级 → 24 个数量级, 爆 | `eta2/(C1+eta2)` |
| `C1 * (yw)^(-1)` | 语法不支持负幂 | `C1 * inv(yw + C2)` |

## 括号风格

乘号显式写出更安全: `C1 * (x)` 优于 `C1(x)`。
