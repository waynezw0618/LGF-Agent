# Pope 不变量与 ASM 闭合的代数结构

## 1. 完整性基 (integrity basis)

对对称张量 `S` 与反对称张量 `W`, 张量多项式张成的空间由 **5 个标量不变量** 参数化
(Pope 1975, JFM 72:331):

| Pope | 表达 | 本工程变量名 | 物理含义 |
|---|---|---|---|
| I₁ | `tr(S²)` | `eta2` | 应变率强度 (≥0), 跨工况 1e-6 → 3e2 |
| I₂ | `tr(W²)` | `zeta2` | 旋转率强度 (≥0) |
| I₃ | `tr(S³)` | `s3` | 应变率三阶不变量 |
| I₄ | `tr(S W²)` | `so2` | 应变-旋转耦合 |
| I₅ | `tr(S²W²)` | `s2o2` | 应变²-旋转²耦合 |

**ASM 展开**: `b = Σ_m a_m(Θ) · T⁽ᵐ⁾`, 其中 `T⁽ᵐ⁾` 是 S、W、Ω 构成的基张量,
`a_m(Θ)` 只依赖上述不变量 (Cayley-Hamilton 定理的直接后果)。

## 2. 局部标量扩展 (非不变量, 但合法)

- `ret = k²/(νε)` — 局部湍流雷诺数 (低-Re 近壁阻尼变量)
- `roloc = 2Ωk/ε` — 局部旋转数 (带符号; **区分 5 个旋转工况的核心变量**)
- `yw = 1-|y/h|` — 无量纲真壁距 (**非局部量**, 壁面扩展)

> 为什么允许非不变量: 本工程 2026-10-11 的 vw-only 轮证实, **只看局部不变量不够** ——
> 加真壁距 `yw` 后 PySR/m 才到 SOTA (0.0329)。物理上, 壁面是外部边界条件,
> 不能由局部不变量唯一确定。

## 3. 关键陷阱 (踩过的坑)

### 3.1 大幂次会爆
近壁 `eta2` 从 1e-6 变到 1e2 (8 个数量级)。`eta2^3` 的动态范围是 24 个数量级,
数值上不可用。**用比值或对数**: `log(eta2+eps)`、`eta2/(C+eta2)`。

### 3.2 单分量上"能否写成 G·T"没有约束力
2026-10-16 诊断: 只拟合 b23 时, 每点 2 个自由系数即可精确复现 b23。
**真正的约束力来自"同一组系数同时闭合 6 分量"** —— 这是高阶/全局耦合,
不是逐通道能验证的。

### 3.3 抵消比 (cancel ratio) 是病态性的直接量度
`Σ‖C_m‖ / ‖b23‖` 实测 **99–32201×**。含义: 各通道项需相互抵消 2–4 个数量级
才得到净 b23。后果: 系数自身拟合到 1e-6, 重组 b23 却爆到 3.8–4.5。
**修复方向**: 加权白化 (`basisB2` 口径) —— 让白化后的系数 `β` 满足 `|β|² ≤ 5`,
抵消消失, 且逐通道独立拟合与联合拟合等价。

### 3.4 奇偶性: 别把断言当事实
`b23` 关于槽道中心 `y→-y` 为 **偶对称**; `T1_23 / T5_23 / T6_23 / T10_23` 与它同类。
把"T1s 反对称"写进 prompt 是**错误断言** (详见 `T1s` 的历史 bug)。
本框架由 C1 探针机器裁决此类断言。

## 4. 推荐的结构骨架 (经验, 非定理)

高旋转下流动准二维化, 系数常出现饱和/衰减:
`tanh(C·roloc)`、`C/(C'+roloc)`、`exp(-C·roloc)`、`√roloc`。

近壁 `eta2/ret` 急剧变化, 常用 `log(eta2+eps)`、`1/√ret`、`eta2/(C+eta2)`。

**硬规则**: 5 个旋转工况必须共享同一组**全局常数** `C#`; 逐工况常数 `K#` 一律拒绝。
